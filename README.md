## 任务介绍

当一个无人快递车第一次来到复杂街区时，如何准确识别门牌号？
赛题提供街景门牌数据集，要求选手设计解决方案实现门牌号正确预测，属于典型字符识别任务。

## 数据集介绍

赛题基于Google街景门牌号数据集（SVHN）采样生成，具体如下：

| 数据集类型 | 规模   | 标注信息                     |
|------------|--------|------------------------------|
| 训练集     | 3W张   | RGB图像+编码+字符位置         |
| 验证集     | 1W张   | RGB图像+编码+字符位置         |
| 测试集     | 4W张   | 仅RGB图像，无编码与字符位置   |

### 标注字段说明

| Field  | Description       |
|-------|-------------------|
| top   | 左上角坐标Y       |
| height| 字符高度          |
| left  | 左上角坐标X       |
| width | 字符宽度          |
| label | 字符编码          |

### 示例标注

```
"000001.png": {

"height": [32, 32],

"label": [2, 3],

"left": [77, 98],

"top": [29, 25],

"width": [23, 26]

}
```

### 矩形检测框表示方式

1. 左上角坐标 + 检测框高度 + 检测框宽度
2. 左上角坐标 + 右下角坐标

基于交叉熵损失函数，加入**标签平滑（Label Smoothing）**：

- 原GT标签如`[1,0,0]`调整为`[0.9,0.05,0.05]`
- 优点：
  1. 提升模型泛化能力
  2. 防止模型过度自信，缓解过拟合
  3. 对标签噪声有一定抗干扰能力

## 改进思路

1. **Baseline优化**：选用更深/更先进的CNN或其他模型，调整数据增强、损失函数、超参数等；
2. **目标检测方案**：利用数字检测框数据，将不同数字作为检测类训练目标检测模型（如YOLO系列：[ultralytics/ultralytics](https://github.com/ultralytics/ultralytics)）；
3. **场景文本识别方案**：将数字视为场景文本，训练文本检测模型获取精准文本框，再微调文本识别模型（无需从头训练）；
4. **模型集成**：综合不同模型预测结果，对概率分布或最终结果加权投票。
